# Domain 06: Human Capital Management (رأس المال البشري)

> Workforce, Payroll, and Performance.

## Capabilities

| Capability | Feature Groups |
|---|---|
| **WorkforceAdmin** | Employees, HR Admin, Departments, Contracts, Loans, Relations, Contingent Workers, Expat Management, Org Structure |
| **TimeAttendance** | Attendance, Biometrics, Leave, Workforce Scheduling |
| **Payroll** | Salary Calculation, Payroll Cycles, Components, Benefits, Compensation, EOSB, Post-Payroll |
| **TalentManagement** | Recruitment, Onboarding, Performance, Learning, Succession |
| **EmployeeServices** | Employee Portal, Travel & Expenses, Employee Assets, Wellness, EHS |
| **Communications** | Announcements, Surveys, Knowledge Base, Expertise |
| **DocumentManagement** | Document Templates, Employee Files |
