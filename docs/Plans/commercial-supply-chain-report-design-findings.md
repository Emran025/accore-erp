# Commercial and Supply Chain Report Design Findings

## Selected visual direction

The shared template will use a **modern Arabic executive-report layout**: a branded dark-slate header with a compact report title and reference block; two-column party or context information; a high-contrast table header; financial summary cards; contextual notes; and a formal approval/footer region. It will use the application’s existing `Cairo` font, RTL direction, and blue-and-slate brand palette.

This direction retains the clarity visible in professional Arabic invoice layouts while avoiding dense grid-heavy forms. It is suitable for invoices, customer and supplier statements, sales and procurement activity reports, inventory balances, returns, and quotations.

## Reference findings

| Reference | Applied finding |
|---|---|
| Qoyod customer statement template | Statements need a clear header, chronological financial activity table, document type, reference number, debit, credit, running balance, closing balance, and an approval/footer area. |
| Tally Saudi VAT invoice guidance | Invoice output should visibly include seller and buyer identity, sequential document number, issue date, descriptions, amount excluding tax, VAT rate and amount, total including VAT, and a QR-code-ready region. |
| Arabic invoice and inventory references | Arabic reports remain most readable with RTL hierarchy, compact identity blocks, a table-led body, strong total separation, and a restrained color system. Inventory reports should prioritize item identity, opening/incoming/outgoing/balance or available stock, valuation, and reorder context. |
